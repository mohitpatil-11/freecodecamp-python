# freecodecamp-python
# freeCodeCamp Python Projects

Projects from my freeCodeCamp Python Developer Certification.

| Project | Description | Run |
|---|---|---|
| Budget App | Spending categories, transfers, and a spend chart | `python "Budget App/demo.py"` |
| Hash Table | Custom hash table with collision handling | `python Hash_Table/demo.py` |
| Polygon Area Calculator | Rectangle and Square classes | `python "Polygon Area Calculator/demo.py"` |
| Tower of Hanoi | Recursive solver that prints every step | `python "Tower of Hanoi/demo.py"` |
| Configuration Manager | Add, update, delete and view user settings | `python "Configuration Manager/demo.py"` |

## How to run

1. Install Python 3.10 or newer.
2. Clone the repo:
   `git clone https://github.com/mohitpatil-11/freecodecamp-python`
3. Open a terminal in the repo folder and run any command from the table above.

No extra packages are needed for the demos.
